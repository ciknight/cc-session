# 会话页发送框：自动隐藏功能已移除

日期：2026-10-28

## 当前行为

移动端自动隐藏/回弹在手机端存在显示问题，已按用户要求整体移除，不再按设备做例外处理。

- 所有设备的会话页发送框均保留在纵向 flex 布局底部，滚动消息时常驻。
- 移除隐藏样式、滑出动画、滚动与 scrollend 监听、回弹定时器及 iOS 特判。
- 滚动停止不再触发回弹顶底。
- 保留进入会话滚到底部、新消息贴底跟随、翻看历史不打扰、加载更早的高度补偿。
- 新建会话页、⚙ 浮层与队列浮层不受影响。

## 回归验证

`tests/test_frontend_controls.js` 覆盖自动隐藏代码移除，以及移动端、iPhone、iPad 和桌面端
进入会话后滚动不隐藏发送框、不安排回弹定时器、滚动停止不改变阅读位置。

运行：`node --test tests/test_frontend_controls.js`。
